# Student Management System

## Project Overview
A full-stack Student Management System developed using Spring Boot and React.

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Data JPA
- MySQL

### Frontend
- React.js
- HTML
- CSS
- JavaScript

## Features
- Add Student
- View Student Details
- Update Student
- Delete Student

## Project Structure

Backend - Spring Boot REST API  
Frontend - React Application

## How to Run Backend

1. Open Backend folder
2. Run Spring Boot application

## How to Run Frontend

```bash
npm install
npm start
